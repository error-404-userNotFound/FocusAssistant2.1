# Changelog

## 2.1.0

- Prepare a clean distributable source tree, MIT license and contribution/privacy
  documentation; exclude personal paths, sessions, logs and local environments.
- Add a project-local setup/launcher workflow, installation diagnostics and
  friendly missing-Python/Tk messages.
- Use a stable per-user `FocusAssistant` data directory separate from the earlier
  development copy.
- Add macOS app-bundle packaging with browser resources and permission usage text,
  plus native Apple Silicon/Intel CI matrices and manual app-build artifacts.
- Retain opt-in guarded close/recovery, Space-aware reminders, local-model
  approval for visible correction requests and three-pass uncertain assessment.

This is an experimental release, not a claim of notarization or complete live
intervention testing on every supported Mac.
